Analisis Kualitas Portofolio Kredit Menggunakan Python

Studi kasus analisis risiko portofolio kredit menggunakan bahasa pemrograman Python. Proyek ini berfokus pada evaluasi Non-Performing Loan (NPL) berdasarkan jenis pinjaman, melakukan uji signifikansi statistik menggunakan Chi-Square dan Fisher's Exact Test, serta membandingkan sensitivitas definisi NPL antara status sistem versus aktual tunggakan 90 hari.
